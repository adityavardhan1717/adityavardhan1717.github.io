Dataset

Meta Microservices Trace Dataset (Huye, Shkuro & Sambasivan, USENIX ATC 2023) — ~6.59M production traces from Meta's internal microservice fleet, spanning thousands of services.

primary

Percentile Thresholds

Flags traces whose latency or span-count falls outside a defined percentile band relative to the service's normal distribution — the main detection method used.

alt

Z-Score

Standardizes span duration against the mean and standard deviation of a service's typical behaviour to catch statistical outliers.

alt

IQR (Interquartile Range)

Uses the spread between the 25th and 75th percentile to flag traces falling well outside the normal operating range — robust to extreme outliers.

alt

MAD (Median Absolute Deviation)

A more robust alternative to standard deviation-based methods, less sensitive to the extreme skew common in production latency data.

Why it matters

Most observability tools react after a service has already failed. This finding flips that — a missing span is a leading indicator, not a symptom, so a monitoring system could flag a likely failure while the request is still in flight, before it reaches the user as an error.

Source

Huye, D., Shkuro, Y. & Sambasivan, R. "Lifting the Veil on Meta's Microservice Architecture." USENIX ATC, 2023 · Full pipeline built as a 46-cell Jupyter notebook covering data cleaning, EDA, and statistical modelling.
