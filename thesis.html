Finding Performance Problems in Microservices: Statistical Analysis of Real Production Data

How do you catch a distributed system failing before a user ever sees an error? This thesis analyzes 6.59M real production traces to find out — and finds a signal most monitoring tools miss entirely.

Supervisor Eric McNamara
Institution TUS Limerick
Traces 6.59M
Methods 4
01

Research question

The question

Can statistical anomaly-detection methods, applied to production distributed-tracing data, reliably flag failing microservices — and can that signal arrive early enough to be useful before an outage is visible to users?

The gap

Most observability tooling (dashboards, alerting, APM) is reactive — it tells you a service failed after error rates or latency already spiked. By then, the user has already felt it.

The approach

Instead of watching for failure symptoms, this thesis looks at structural properties of the trace itself — specifically, whether expected spans are missing — as an earlier, cheaper signal.

Methods compared

primary

Percentile Thresholds

Flags traces whose latency or span-count falls outside a defined percentile band relative to the service's normal distribution.

flag if x > P95(service)
alt

Z-Score

Standardizes span duration against the mean and standard deviation of a service's typical behaviour.

z = (x − μ) / σ
alt

IQR

Uses the 25th–75th percentile spread to flag traces well outside the normal range — robust to extreme outliers.

flag if x > Q3 + 1.5×IQR
alt

MAD

A more robust alternative to stddev-based methods, less sensitive to the extreme skew common in production latency data.

flag if |x − median| > k×MAD

Why it matters

Most observability tools react after a service has already failed. This finding flips that — a missing span is a leading indicator, not a symptom, so a monitoring system could flag a likely failure while the request is still in flight, before it ever reaches the user as an error.

Dataset: Huye, D., Shkuro, Y. & Sambasivan, R. "Lifting the Veil on Meta's Microservice Architecture." USENIX ATC, 2023.
